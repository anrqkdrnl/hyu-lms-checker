# LMS 체커 — 한양대 LMS 할 일 알리미 (macOS)

한양대 LMS(learning.hanyang.ac.kr)에서 **아직 안 들은 사이버강의, 마감이 지난 미제출 과제, 7일 안에 마감되는 할 일**을 한 화면에 모아서 보여주는 Mac 앱이에요.

- **설치하고 계정만 입력하면 끝**: 터미널, Python, 토큰 발급 같은 준비가 필요 없어요.
- **원하는 시각에 자동 확인**: 정해둔 시각(기본 매일 05:00, 하루 여러 번도 가능)에 확인해서 결과 창과 알림을 띄워줘요.
- **읽기 전용**: 강의 재생, 출석 처리, 과제 제출처럼 LMS 상태를 바꾸는 동작은 절대 하지 않아요.
- **계정 정보는 내 Mac에만**: 아이디와 비밀번호는 macOS 키체인에 저장되고, 학교 로그인 페이지 말고는 어디로도 보내지 않아요.

> 학생이 개인적으로 만든 비공식 도구예요. 한양대학교와는 관련이 없어요.

## 설치하기

### 요구 사항

- macOS 14 (Sonoma) 이상
- Apple Silicon과 Intel Mac 모두 지원
- 한양대 포털 아이디와 비밀번호

### 방법 A: Homebrew로 설치 (추천)

[Homebrew](https://brew.sh)를 쓰고 있다면 터미널에 아래 명령을 붙여 넣으면 끝이에요. 보안 경고도 뜨지 않아요.

```bash
brew tap anrqkdrnl/tap
brew trust anrqkdrnl/tap        # Homebrew 7 이상에서 필요해요 (예전 버전이면 생략)
brew install --cask lms-checker
```

설치가 끝나면 응용 프로그램 폴더에서 **`LMS 체커`**을 열면 돼요.

- 업데이트: `brew upgrade --cask lms-checker`
- 삭제: `brew uninstall --cask lms-checker` (앱 데이터까지 지우려면 `--zap`을 붙여요)

> `brew trust`는 Homebrew 공식 저장소가 아닌 tap(개인 저장소)을 믿고 쓰겠다고 등록하는 명령이에요. 이 tap에 들어 있는 설치 스크립트는 [anrqkdrnl/homebrew-tap](https://github.com/anrqkdrnl/homebrew-tap)에서 직접 확인할 수 있어요.

### 방법 B: 직접 다운로드

#### 1. 다운로드

[**Releases**](../../releases/latest) 페이지에서 `LMSChecker.zip`을 받아서 압축을 풀어요.

#### 2. 응용 프로그램 폴더로 옮기기

압축을 풀면 나오는 **`LMS 체커.app`**을 Finder의 **응용 프로그램** 폴더로 드래그해요.

> 자동 실행을 쓰려면 응용 프로그램 폴더에 두는 걸 권장해요. 나중에 앱 위치를 옮겨도 앱을 한 번 열면 자동 실행 경로가 알아서 갱신돼요.

#### 3. 처음 열기 (보안 경고 넘기기)

Apple 유료 개발자 인증을 받지 않은 앱이라서 처음 열 때 macOS가 막아요. **한 번만** 아래처럼 허용하면 돼요.

**macOS 15 (Sequoia) 이상**
1. `LMS 체커`를 더블클릭해요. "열 수 없음" 경고가 뜨면 **완료**를 눌러요.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 가요.
3. 아래쪽에 있는 *"LMS 체커"이(가) 차단되었습니다* 옆의 **그래도 열기**를 누르고 암호를 입력해요.

**macOS 14 (Sonoma)**
- Finder에서 앱을 **우클릭(또는 control+클릭) → 열기 → 열기**를 눌러요.

**터미널이 편하다면** (위 방법 대신)

```bash
xattr -dr com.apple.quarantine "/Applications/LMS 체커.app"
```

## 처음 실행하기 (설정 마법사)

처음 열면 설정 마법사가 떠요.

1. **환영**: 앱이 하는 일을 보여줘요. **시작하기**를 눌러요.
2. **계정 연결**: 한양대 포털 아이디와 비밀번호를 입력하고 **로그인 확인**을 눌러요.
   - 앱 안에서 실제로 LMS에 로그인해 보고, 성공해야만 키체인에 저장해요.
   - 실패하면 이유가 표시돼요 (예: 비밀번호 오류, 네트워크 문제).
3. **자동 확인**:
   - **자동 확인**: 켜 두는 걸 권장해요. 확인 시각도 여기서 정할 수 있어요.
   - **알림 받기**: 켜면 macOS가 알림을 허용할지 물어봐요. **허용**을 눌러 주세요.
   - **완료하고 지금 확인**을 누르면 첫 확인이 시작되고, 보통 10~30초 걸려요.

## 자동 확인 (시각 설정)

- **확인 시각은 직접 정해요.** 설정(⌘,) → **자동 실행**에서 시각을 바꾸거나, **시각 추가**로 하루 최대 6번까지 넣을 수 있어요 (예: `07:30`, `13:00`, `19:00`). 기본값은 `05:00` 하루 1번이에요.
- 앱이 macOS에 작은 예약 작업(LaunchAgent)을 등록해요. 이 작업이 10분마다 앱을 잠깐 깨워서, **정한 시각이 지났는데 아직 확인 안 한 회차가 있으면** 1번 확인해요. 그래서 실제 확인은 정한 시각부터 10분 안에 이뤄져요.
- 그 시각에 Mac이 잠자고 있었으면 깨어난 뒤 처음 쓸 때 확인해요. 여러 회차를 놓쳤어도 1번만 확인해요.
- 그 사이에 **지금 확인**을 눌렀다면 그 회차는 이미 확인한 걸로 쳐요.
- 확인이 끝나면 **결과 창**과 **알림**을 띄워요.
  - 알림 예시: `강의 3 · 미제출 0 · 오늘/내일 마감 1 · 7일 내 2`
- **일시적인 오류**(Mac이 막 깨어나서 인터넷이 아직 안 붙었을 때 등)가 나면 10분 뒤에 다시 시도해요. 3번째에도 실패하면 오류 내용을 보여줘요.
- **로그인 거부**(비밀번호가 바뀌었을 때 등)는 계정이 잠기지 않도록 그날 남은 회차는 건너뛰고, 바로 알려줘요. **지금 확인**에 성공하면 다시 자동 확인이 이어져요.
- 끄려면 설정에서 **자동 확인**을 꺼요.

## 자주 묻는 질문 / 문제 해결

**Q. 비밀번호를 앱에 저장해도 안전한가요?**
macOS 키체인에 저장돼요. 키체인은 Safari나 Chrome이 비밀번호를 저장하는 곳과 같은 보안 저장소예요. 앱은 이 비밀번호를 한양대 로그인 페이지(`learning.hanyang.ac.kr`, `api.hanyang.ac.kr`)에 입력할 때만 써요. 키체인 접근.app에서 `hyu-lms-id`, `hyu-lms-pw`로 검색하면 직접 확인하거나 지울 수 있어요.

**Q. "로그인이 거부됐어"라고 나와요.**
포털 비밀번호를 바꿨거나 계정이 잠겼을 수 있어요. 설정에서 비밀번호를 다시 저장하고 **지금 확인**을 눌러 보세요. 학교 포털 사이트에서 직접 로그인되는지도 확인해 보세요.

**Q. "응답이 없어 (네트워크 확인)"이라고 나와요.**
인터넷 연결을 확인하고 다시 시도해 보세요. 학교 서버 점검 시간일 수도 있어요.

**Q. "강의 조회 실패"만 나오고 과제는 잘 나와요.**
주차학습(LearningX) 쪽 일시적인 문제예요. 잠시 뒤 **지금 확인**을 다시 눌러 보세요. 과제 목록은 따로 조회하기 때문에 영향을 받지 않아요.

**Q. 정한 시각에 창이 안 떠요.**
- 설정에서 **자동 확인**이 켜져 있는지, 확인 시각이 맞는지 봐 주세요. 정한 시각부터 10분 안에 확인해요.
- 오늘 이미 확인했으면 그날은 다시 띄우지 않아요.
- 알림이 안 오면 **시스템 설정 → 알림 → LMS 체커**에서 알림을 허용해 주세요.

**Q. 강의를 대신 들어주나요?**
아니요. 이 앱은 **목록을 확인만** 해요. 재생이나 출석 처리 기능은 없고 앞으로도 넣지 않아요.

**Q. 예전 터미널(Python) 버전을 쓰고 있었어요.**
설정 화면에 **예전 버전 자동 실행 끄기** 버튼이 나타나요. 눌러서 끄면 팝업이 두 번 뜨지 않아요. 예전 코드는 [`legacy-python/`](legacy-python/)에 남겨 뒀어요.

## 삭제하기

**Homebrew로 설치했다면**

```bash
brew uninstall --cask lms-checker          # 앱 + 자동 실행 등록 삭제
brew uninstall --zap --cask lms-checker    # 앱 데이터와 설정까지 삭제
```

키체인에 저장된 계정 정보는 Homebrew가 지우지 않아요. 완전히 지우려면 `security delete-generic-password -s hyu-lms-id; security delete-generic-password -s hyu-lms-pw`를 실행해요.

**직접 다운로드했다면**

1. 설정에서 **자동 확인**을 꺼요. 자동 실행 등록이 지워져요.
2. 응용 프로그램 폴더에서 `LMS 체커.app`을 휴지통으로 옮겨요.
3. (선택) 데이터와 계정 정보도 지우려면:

   ```bash
   rm -rf ~/Library/Application\ Support/LMS\ 체커
   defaults delete com.seongsu.lmschecker
   security delete-generic-password -s hyu-lms-id; security delete-generic-password -s hyu-lms-pw
   ```

   자동 확인을 끄지 않고 앱을 지웠다면 아래 명령도 실행해 주세요:

   ```bash
   launchctl bootout gui/$(id -u)/com.seongsu.lmschecker.auto
   rm ~/Library/LaunchAgents/com.seongsu.lmschecker.auto.plist
   ```

## 동작 방식 (개발자용)

```
LMS 체커.app ─ (보이지 않는) 앱 안 브라우저(WKWebView)
   1. learning.hanyang.ac.kr 접속 → 로그인 폼(#uid/#upw)이면 키체인 계정으로 한양 통합 로그인
   2. 로그인된 페이지 안에서 Canvas API 호출 (세션 쿠키 사용 → 액세스 토큰 불필요)
        /api/v1/courses?enrollment_state=active      과목 목록
        /api/v1/planner/items                        7일 내 할 일
        /api/v1/users/self/missing_submissions       미제출
   3. 주차학습(/courses/{id}/external_tools/140)을 한 번 열어 xn_api_token 쿠키를 받음
        /learningx/api/v1/courses/{id}/modules       강의 목록 + 출석 기간/완료 여부
   4. 결과 → ~/Library/Application Support/LMS 체커/latest.json → 화면

launchd (10분마다) → LMS 체커 --auto → 확인 시각 회차 가드 → 위 과정 → 결과 창 + 알림
```

- 강의 판별 기준: `content_type == attendance_item`, 영상 종류가 `mp4`/`movie`/`screenlecture`, `use_attendance == true`, 미완료, `lecture_period_status`가 `open`(마감 = `due_at`)이거나 `late`(마감 = `late_at`).
- 페이지에서 하는 동작은 이동, 로그인 폼 입력, 조회용 `fetch(GET)`뿐이에요.

### 파일 위치

| 경로 | 내용 |
|---|---|
| `~/Library/Application Support/LMS 체커/latest.json` | 마지막 결과 |
| `~/Library/Application Support/LMS 체커/error.log` | 오류 기록 |
| `~/Library/LaunchAgents/com.seongsu.lmschecker.auto.plist` | 자동 실행 등록 |
| 키체인 `hyu-lms-id` / `hyu-lms-pw` | 포털 아이디 / 비밀번호 |
| `defaults read com.seongsu.lmschecker` | 마지막 실행일, 설정 완료 여부 |

## 소스에서 빌드하기

Xcode가 필요해요. App Store에서 설치한 뒤 한 번 실행해서 라이선스에 동의해 두세요. Command Line Tools만 있으면 SwiftUI 매크로가 없어서 빌드가 실패해요.

```bash
git clone https://github.com/anrqkdrnl/hyu-lms-checker.git
cd hyu-lms-checker
./build.sh --install     # 빌드 + /Applications 설치
./build.sh --zip         # 배포용 build/LMSChecker.zip
```

```
hyu-lms-checker/
├── build.sh               # 빌드 / 설치 / zip
├── VERSION
├── app/
│   ├── LMSApp.swift       # 조회 엔진, 화면, 자동 실행 흐름
│   ├── Shared.swift       # 앱 안 브라우저, 키체인, launchd, 설정 마법사, 공용 뷰
│   ├── make_icon.swift    # 아이콘 생성
│   └── build_bundle.sh    # swiftc로 universal 앱 번들 생성 + ad-hoc 서명
└── legacy-python/         # 예전 터미널(Python + Playwright) 버전
```

- Xcode 프로젝트 없이 `swiftc`로 바로 컴파일해요. arm64와 x86_64로 각각 빌드한 뒤 `lipo`로 합쳐요.
- 개발용 플래그:
  - `LMS 체커.app/Contents/MacOS/LMSChecker --selftest`: 조회 결과 요약을 출력하고 종료해요.
  - `--auto`: launchd가 쓰는 모드예요.
